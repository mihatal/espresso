# Эспрессо-лаб — маршрут вкуса

Личный тренажёр вкуса для домашней эспрессо-машины De'Longhi Dedica.
Шестинедельный маршрут, калькулятор шота с таймером, компас вкуса, журнал дегустаций,
хронометраж экстракции, шкала помола в честном масштабе и смета.

Живая страница: https://mihatal.github.io/espresso/
